## 🔬 蒸馏方法论

这个 Skill 的创建遵循了"蒸馏身边人"的特殊流程：

```
公开信息搜索 → 用户第一手观察 → 用户迭代反馈 → 真实录音转写
   （骨架）        （血肉）          （张力）           （灵魂）
```

### 素材层级

| 层级 | 来源 | 价值 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 真实录音转写 | **原话**，直接可用 |
| ⭐⭐⭐⭐ | 微信聊天记录 | 看到公开外的另一面 |
| ⭐⭐⭐ | 学生第一手观察 | 行为细节、"黑暗面" |
| ⭐⭐ | 公开报道/活动记录 | 职务信息、理念名称 |
| ⭐ | 搜索引擎结果 | 基础背景 |

### 关键发现

- **录音转写是质变分水岭**——从"模仿"升级为"复刻"
- **不回避暗面**——飞踢、罚站、退宿等管理手段才让角色真实
- **张力即深度**——"理念 vs 行为"的矛盾比光滑形象更有价值
- **称谓切换是核心机制**——"水哥"和"王老师"是同一个人但完全不同的两副面孔
